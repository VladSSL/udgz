# Сайт УДГЗ для GitHub Pages

В архиве актуальная опубликованная версия: новое фото на первом экране и исправленное видео.

## Как опубликовать

1. Распакуйте архив.
2. Загрузите всё содержимое в корень репозитория GitHub. Файл index.html должен быть в корне, папка assets — рядом с ним.
3. Откройте Settings → Pages.
4. В Source выберите Deploy from a branch, затем main и / (root). Нажмите Save.
5. После публикации ссылка появится в разделе Pages.

Сборка и установка зависимостей не нужны. Папку assets загружайте целиком, включая видео и PDF.

## Что где менять

- index.html — тексты, структура, характеристики и SEO.
- styles.css — оформление и адаптивная версия.
- app.js — видео, анимация, форма и цели Метрики.
- assets/ — фотографии, исправленное видео hardening-web.mp4 и коммерческое предложение.

Видео подготовлено как MP4 H.264/AAC с быстрым стартом. Качество при перепаковке сохранено.

## Форма запроса КП

Форма открывает почтовую программу с готовым письмом на info@rusplasma.com. Для прямой отправки в CRM нужен серверный обработчик и подключение CRM.

## Яндекс Метрика

Укажите номер счётчика в METRIKA_ID в app.js. Пока значение пустое, Метрика не подключается.

## Адрес сайта в SEO

После публикации замените адрес прежнего сайта https://udgz-plasma-hardening.mechanic-tea-7150.chatgpt.site в canonical, og:url и og:image в index.html на свой адрес GitHub Pages или домен. На работу страницы это не влияет.
